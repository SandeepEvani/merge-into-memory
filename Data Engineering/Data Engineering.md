>[!Definition]
>Data Engineering is the development, implementation and maintenance of systems the take in raw data and produce high quality, consistent information that supports downstream use cases such as analytics, machine learning and business intelligence.

## The Data Engineering lifecycle

The end goal of data is that it must be served. From generation of data to the serving of it, there are different stages involved, which is called as the Data Engineering lifecycle

The stages are as follows:
- Generation :: Is where the data is born.
- Storage :: It acts a connective tissue for the rest of the stages
- Ingestion :: The process of pulling(extracting) data from source systems into your storage layers
- Transformation :: Modifying the data as per the downstream needs.
- Serving :: The data is ready to be consumed from this layer

There are also some undercurrents for the data engineering lifecycle::
- Security
- Data Management
- DataOps
- Data Architecture
- Orchestration
- Software engineering

## Data Engineer's Skills and Activities

A Data Engineer must be able to constantly optimize along the axes of cost, agility, scalability, simplicity, reuse and Interoperability

### Data Maturity
Data Maturity is the extent in which the data is utilized to make informed decisions across the organization

>[!Definition]
>Data Maturity is the progression higher data utilization, capabilities and integration across the organization

The data maturity model has 3 stages:
- Starting with data
- Scaling with data
- Leading with data

**Starting with data** :: The company may have loosely or no data goals defined. Adoption and Utilization are likely low or non-existent.
**Scaling with data** :: The company has a set of data goals and has moved away from ad hoc requests
**Leading with data** :: The company is data-driven at this stage, Automated pipelines and systems allow people to do self-service analytics
