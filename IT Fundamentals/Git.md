Git is a version control software usually used in software development projects to maintain a track of changes done in a particular folder. 


Here is also some common terminology used across the world of Git.

- Repo: A short form for Repository, is a independent unit in which the Git software is enabled for, all the functions of the git are applicable to a repository and does not affect another repository.
- Usually a Repo is a folder containing files or a collection of folders



## Git Commands

### git --version
 - Gives the version of git software being used in the local machine 

### git status

- Gives the status of the specific repository where we create and manage a git repository. Information regarding the branch, commits and local changes in that particular repo and gives an error if there is no git initialized in the folder.

### git init

- Initializes the git repository and starts the tracking of changes happening in that particular folder where we execute the git init

### git add <file_name> |  git add .

- git add command is an instruction to git
