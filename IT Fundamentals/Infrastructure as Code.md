
>[!Definition]
>Infrastructure as Code is defining what infrastructure you need to provision, written and maintained in the form of code.

### Benefits of using Infrastructure as Code

- Infrastructure as code eliminates the errors caused due to misconfiguration of the infrastructure which might occur while doing manually.
- It provides an automated way to deploy infrastructure making the process efficient, faster and consistent across different environments (similar to WORM).
- Infrastructure as code provides a central hub for all the developers in an organization to collaborate and write re-usable code.
- Since code can be versioned, we can employ the CICD practices while integrating and deploying the code, which is deploying your infrastructure in a safe mode.
