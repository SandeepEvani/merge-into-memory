- backend.tf : A backend file contains the backend configuration
- main.tf : entry point for the configuration files
- outputs.tf : contains all the outputs
- variables.tf : contains all the input variables in the alphabetical order
- providers.tf : contains all the provider blocks and their respective configurations
- locals.tf : contains all the local values
- terraform.tf : contains the terraform configuration block mentioning the required versions and the required providers
- override.tf : or \_override.tf and their respective Json variants are special files which are typically taken as override files and depending upon the type of block defined, the override function overrides the definition partially or in its entirety.
