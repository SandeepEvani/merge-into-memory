[[Terraform/Terraform|Terraform]]
There are three editions of Terraform that are available.
- **Terraform Community Version**: Free, downloadable tool which can be used via the command line
- **HCP Terraform**: HashiCorp Cloud Platform or HCP terraform runs Terraform in a stable and remote environment and securely stores the state and other secrets
	- Different methods of interacting with terraform, can use the CLI, The web console, the APIs and integration with VCS
	- Offers private registry, to develop and maintain shareable modules across the organization
	- Free for certain plans and users < 5,  while others include paid plans
	- Enforce best practices and organizational policies with Sentinel
- **Terraform Enterprise**: Allows you to set up a self-hosted version of the HCP Terraform
