
Basically cloud computing came into the picture to answer and resolve the traditional IT Datacenter challenges.

Characteristics of cloud computing
- Obtain/procure resources within minutes
- Pay per use
- Elasticity

Cloud deployment Models.
- Private cloud - Traditional IT datacenter
- Public cloud - Secure cloud service for the public
- Hybrid cloud - A combination of private and public cloud
- Multi cloud - Spanning across multiple cloud providers

Major Cloud computing providers :: AWS, Azure, GCP.
